# Provenance

DizgiDEX Typst Renderer is a small, subject-neutral JSON-to-PDF renderer built on Typst. The included example uses invented text; no customer or publisher content, bundled fonts, or generated PDFs are part of this release.

The specification and implementation were prepared with AI assistance from OpenAI Codex at the maintainer's direction. No external human contributions are recorded for this initial release.

Typst, Python, Poppler, the development packages, and the named system fonts are external tools or dependencies; their code and font files are not vendored here. See [DEPENDENCIES.md](DEPENDENCIES.md) for details.
